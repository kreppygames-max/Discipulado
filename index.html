Configure suas chaves do Supabase

Abra este arquivo HTML em um editor de texto (ex: Bloco de Notas) e preencha as duas linhas no topo do arquivo:

const SUPABASE_URL = 'COLE_SUA_URL_AQUI';
const SUPABASE_KEY = 'COLE_SUA_ANON_KEY_AQUI';

Onde encontrar:
→ Acesse supabase.com → seu projeto
→ Project Settings → API
→ Copie a Project URL e a chave anon public

Depois de preencher, salve o arquivo e abra novamente no navegador.
